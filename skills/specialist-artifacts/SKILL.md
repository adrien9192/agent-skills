# Specialist artifacts

Choose only the requested deliverable:

- Technical diagram (including a repository architecture or Stripe sequence) → read `skill://archify` in OMP, or `$HOME/.agents/skills/archify/SKILL.md` in Claude/Codex.
- Educational course, slides plus quiz, teaching simulation, PBL or educational PPTX → read `skill://openmaic` in OMP, or `$HOME/.agents/skills/openmaic/SKILL.md` in Claude/Codex.

These payloads are explicit-only and loaded on demand through this small index. An ordinary code change, text explanation, business deck or non-pedagogical simulation stays with the existing workflow. Load neither capability merely because a project uses Stripe or has architecture.
